## 一句话直觉

机器学习的最小骨架只有一句话：**给模型一个带参数的猜测函数，用数据算出猜得多差，再朝着"差得少一点"的方向调参数**。大模型的训练也是这三步，只是参数从 2 个变成了千亿个。

## 用一条直线看懂"训练"

假设要预测"学习时长 → 分数"，最简单的模型是一条直线 `y = w·x + b`。训练前 w 和 b 是乱猜的，训练做的事：

1. **前向**：把每个学习时长代入直线，得到预测分数
2. **算损失**：预测分和真实分的差距求平均（均方误差），这个数字衡量"现在有多差"
3. **调参数**：往"让差距变小"的方向微调 w 和 b，重复几百次

循环结束后，直线就"拟合"了数据。所谓**训练**，从来都是这三步的放大版。

## 机器学习和大模型的关系

把这条直线换成一个有几十层、千亿参数的函数，把"学习时长"换成"前 999 个 token"，把"分数"换成"第 1000 个 token 的概率"——就是你在模块 2 学过的预训练。**梯度、损失、调参数，三个概念贯穿始终**；后面的微调（LoRA）、对齐（RLHF/DPO），全都是在这套骨架上换花样。

## 最小可用知识清单

进入后面的课程，你只需要记住这几个词：**参数**（模型里可调的数字）、**损失**（衡量预测好坏的单个数字，越小越好）、**梯度**（每个参数该往哪边调、调多猛的指引）、**过拟合**（把训练数据背下来了但不会举一反三——参数大而数据少的典型症状，预训练一节提过）。

## 眼见为实

下面的代码不依赖任何库，手写一个最小二乘拟合：对 5 个数据点求出最合适的 w 和 b，然后看它预测没见过的输入。

## 可选代码片段

### 最小二乘：不循环也能"训练"的直线拟合

```python
x = [1, 2, 3, 4, 5]          # 学习时长（小时）
y = [52, 58, 65, 71, 79]     # 考试分数

n = len(x)
mx, my = sum(x) / n, sum(y) / n
w = sum((xi - mx) * (yi - my) for xi, yi in zip(x, y)) / sum((xi - mx) ** 2 for xi in x)
b = my - w * mx
print(f"拟合结果: 分数 = {w:.2f} × 时长 + {b:.2f}")
print("预测 6 小时的分数:", round(w * 6 + b))
```

## 随堂轻习题

### Q1 · single · ex-ml-1
题干：训练过程中，"损失"这个数字代表？
选项：
- A. 模型参数的个数
- B. 当前预测与正确答案之间的差距
- C. 训练数据的总量
- D. 模型运行的速度
答案：B
解析：损失是衡量"现在猜得多差"的单个数字，训练的全部目标就是让它变小；参数个数和数据量是另两个维度的概念。
知识点：损失函数

### Q2 · judge · ex-ml-2
题干：大模型的训练过程本质上也是"预测 → 算损失 → 调参数"的循环，只是规模巨大。
选项：正确 / 错误
答案：正确
解析：预训练、微调、对齐都是这套骨架：换不同的模型函数、损失定义和数据，训练的最小逻辑不变。
知识点：训练骨架

### Q3 · single · ex-ml-3
题干：参数很大、数据很少的模型，最可能出现的症状是？
选项：
- A. 把训练数据背下来，遇到新情况不会举一反三
- B. 什么都学不会，连训练数据都预测不准
- C. 训练速度一定更快
- D. 输出一定是乱码
答案：A
解析：这是过拟合的典型表现——容量大而数据不足，模型选择"背题"；这也是预训练讲究三要素匹配的原因。
知识点：过拟合
